# HPC Smart Scanner 🚐

> **Fast, offline-capable UK vehicle registration number scanner**

🔗 **Live Demo:** [compstarali1.github.io/Scanner-HPC](https://compstarali1.github.io/Scanner-HPC/)

---

## ✨ Features

- 📷 **Letterbox OCR Scanner** — targeted camera window reads number plates faster and more accurately
- 🔍 **Auto-Matching** — instantly compares scans against your pending list
- 📋 **Bulk Import** — paste registrations, one per line; mark completed with ` - DONE`
- 📊 **Clear Workflow**: Found · Pending · Completed
- 💾 **Save & Export** — backup/restore data; export lists as text files
- 🌙 **Dark / Light Theme** · Torch control · Local auto-save

## 📱 Android APK Available

A standalone **Android app** is also available — **same features, fully offline**:

- ✅ Works **without internet** — OCR runs entirely on your device
- ✅ Faster startup & direct camera access
- ✅ Fully compatible with web version workflow

## 🚀 Quick Start

1. **Paste registrations** → tap **REBUILD**
2. Tap **📷 SCAN** or the floating camera button
3. **Centre plate in the box** → auto-detected and matched instantly
4. Mark complete, restore, or export your list
